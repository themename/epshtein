## Описание программы 
*"Random Quote Generator (Генератор цитат) — это GUI-приложение на Python (Tkinter), которое отображает случайные цитаты из предустановленного списка. Программа позволяет фильтровать цитаты по автору и теме, ведет историю показанных цитат, а разработка ведется с использованием системы контроля версий Git."*
## Требования для запуска 
Что нужно установить на компьютер: - Python 3.10 или выше - Библиотеки: `pip install matplotlib requests` ---
